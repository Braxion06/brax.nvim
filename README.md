
# This is Braxion's Neovim config

This configuration may become bloated over time. Feel free to disable (comment
out or remove) any plugins as needed.

Before cloning please read KICKSTART_README.md, install the dependencies
including tree-sitter-cli (tree-sitter) and read init.lua
from the original [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim) repo.
